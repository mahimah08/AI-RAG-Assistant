# 🤖 AI RAG Assistant

An AI-powered document question-answering application built using Retrieval-Augmented Generation (RAG).

The application allows users to upload documents and ask questions about their content. Relevant information is retrieved from the documents and provided to the AI model to generate accurate, context-aware answers.

## ✨ Features

- 📄 Document-based question answering
- 🔍 Semantic search using vector embeddings
- 🧠 Retrieval-Augmented Generation (RAG)
- 💬 Interactive Streamlit interface
- 📚 Local document processing and retrieval
- ⚡ Fast and context-aware responses
- 🗂️ Persistent vector database using ChromaDB

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **LangChain**
- **ChromaDB**
- **AI / LLM**
- **Vector Embeddings**
- **Git & GitHub**
